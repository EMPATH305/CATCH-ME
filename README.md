# CATCH ME

**Don't label me. Learn me.**

一個會先猜你、再被你打臉，最後慢慢畫出戀愛模式的互動式自我探索遊戲。

## MVP 0.1

- 15 題單人遊戲
- 系統每題先鎖定預測
- CAUGHT / MISSED 即時回饋
- 依前面答案調整後續預測
- 可選 E 自訂回答
- Relationship Blueprint 初步結果頁
- 分享文字複製
- Responsive mobile layout
- 無登入、無後端、無追蹤

## Product direction

CATCH ME 不把使用者塞進固定人格類型。核心 loop 是：

`I predict → You answer → I learn → You go deeper → Blueprint`

後續預計章節：

1. The Crush
2. Flirt With Me
3. After Dark
4. Trust Issues
5. Fight Me
6. Build a Life

未來可探索雙人模式、房間碼、匿名社交結果牆與更長期的 adaptive profile；在驗證單人核心 loop 以前不優先加入帳號與社群系統。

## Run

這是零建置的靜態網站。直接開啟 `index.html`，或使用 GitHub Pages 部署即可。
